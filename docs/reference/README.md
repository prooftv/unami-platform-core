# Reference Material

Historical design artefacts from the platform's initial build phase.

**Never import code from here.**

These folders document the original design process and served as the source
for migrating into `packages/ui` and `packages/shared`.

The platform itself is now the reference.

```
packages/ui      ← use this
packages/shared  ← use this
```

## Contents

- `dashboard-platform-export/` — original theme engine, font system, preference store, CSS presets
- `moments-v2-bootstrap/` — original architecture docs, data models, API contracts, deployment guides
